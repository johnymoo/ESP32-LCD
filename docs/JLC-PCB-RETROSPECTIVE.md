## 需求如何收敛

最初探索现成温控板、RS485/USB 控制、ESP32 驱动及独立显示等方案。用户在淘宝对比并购入显示/风扇后，现成温控板的尺寸和接口集成仍不理想，于是转向自制小型转接板。早期商品搜索和登录过程主要依据会话记录，不把曾讨论/加入购物车的全部商品当作最终采购。

| 阶段 | 用户决策 | 对设计的影响 |
|---|---|---|
| 现成板探索 | 希望少走线、尺寸小、接标准四线风扇 | 仅有本地温感或手动调速的板，不一定有可接 ESP32 的控制/测速接口 |
| 供电简化 | ESP32 经自身 USB-C 供电，风扇独立 12V | 不依赖 GB10 Type-C 提供 12V；电源与控制分开、信号共地 |
| 自制转接板 | ESP32 直接控制风扇 | 载板提供风扇供电、保护、开漏 PWM 和双路测速接口 |
| Rev B 直插 | 屏幕带针，两排排母直接插接 | 排距、编号方向、插入高度及 USB/按键避让成为硬约束 |
| 装配路线 | SMT 报价较高，先试自行焊接现版 | 保持 Rev B 原料号，不在采购时换大封装或删阻容 |
| 后续 Rev C | 手焊困难时再优化封装与数量 | 已建 [issue #1](https://github.com/johnymoo/ESP32-LCD/issues/1)，本批不实施 |

本板设计的最终范围：45×30mm、双层 FR-4；两排 1×11、2.54mm 排母，17.00mm 中心距；显示为 ESP32-S3-Touch-LCD-1.47-M。电气结构为独立12V经保险丝和反接保护供两只风扇，电机电源并联；GPIO1 经 AO3400A 共用开漏 PWM，GPIO2/4 分别测速。屏幕 USB-C 供电，载板不向屏幕送12V。总计16件、11种物料，11件底面贴片＋5件插件。

风扇为140mm Thermalright TL-C14C（12V/0.13A）与60mm Delta AFB0612LB（12V/0.10A）；用户确认台达标准四线并支持测速。标称总电流0.23A不替代启动/热态测试。双TACH不可短接；未供电/复位的硬件默认全速和通信超时的软件全速回退是不同功能，后者固件尚未完成。

## 设计与制造校核的关键修正

| 问题 | 本次处理 | 可复用经验 |
|---|---|---|
| 双排针编号及电源误判风险 | 厂家奇偶针分排；pin8 为3V3、pin6为GND，逐针重建映射 | “带针”不说明接口映射；原理图、机械图、观察面一起核对 |
| GPIO3 为启动配置脚 | 第二路测速改 GPIO4 | 查 MCU 与模块板载占用，不能只看可用针脚名称 |
| 占位器件不能用于采购制造 | 换真实 Device/Symbol/Footprint 并恢复网络 | 只填商城料号不等于器件标准化 |
| 改符号后 NC 标记可能丢失 | 补回真实未连接脚标记，重跑源图检查 | 源图修改后同步 PCB，并核对每个焊盘网络 |
| 插座/电容/保险丝空间 | F1 移到(18,13)mm，F1–J1间距2.36mm；C1–J1间距0.7mm保留装配关注 | 除了 DRC，还要考虑本体和烙铁空间；贴片先焊、高大插件后焊 |
| 开窗露线与丝印 | DFM迭代修正后形成DFM5 | 每次改图重导同版文件，不能用旧DFM背书新板 |
| 排母22脚孔隙提示 | 保留1.00mm孔，厂家推荐1.02±0.05mm支持该选择 | 依据厂家尺寸解释，不为全绿盲目缩孔 |
| 波峰焊治具间距警报 | 记录原计数；当前逐件手焊，不使用该治具工艺 | 规则适用性、厂方承接与实物质量分开记录 |
| 个别 CPL 零度不同 | 仅C1/D1/Q1/J1加180°，保留原CPL，重新导入复核pin1 | 不整体镜像或统一旋转所有底面件 |
| 本地槽孔/预览兼容问题 | Gerbonara 1.6.3解析G85，支持mask/filter的渲染器核对 | 先确认解析器能力，不能将渲染异常当设计损坏 |

原理图检查记录为2026-09-09 07:29:29、零fatal/error/warning；最终PCB DRC为10:27:50、124项零问题。独立审计覆盖40个已联网引脚、16件物料及机械/坐标一致性。DFM5同时包含PCB/SMT报告，报告时间11:46:31。仍有上述工艺/模型提示，不能写成DFM全绿；更不能写成首板实测通过。

## 下次怎么更快、更稳

1. 最开始定好手焊/SMT和试装数量，提前估计加工与最小包装成本。
2. 先取准确板型的引脚/机械资料，锁连接器，再画原理图和布局。
3. 全程用真实料号与封装；源图→PCB同步后做网络、机械和工艺三方面检查。
4. 保留每次有效原生快照，选唯一最终制造包；CPL修正另存并重导验证。
5. 把设计检查、工艺提示、订单审核、生产稿、付款/物流和实物验收拆开记录。
6. 保留动态采购记录在冻结发布包之外；用户手动下单后先查单，不重复购买。
