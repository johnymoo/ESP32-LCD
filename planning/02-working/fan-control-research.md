# 风扇控制设计研究摘要（2026-09-16）

## 现有能力

- ESP32-S3-Touch-LCD 分辨率 320×172，当前固件通过 Wi-Fi HTTP 读取状态 JSON。
- 状态服务返回 `head.temp_c` 与 `worker.temp_c`，刷新周期当前约 2 秒。
- Rev B 转接板：GPIO1 控制两只风扇共用的 25 kHz 开漏 PWM；GPIO2 读取 FAN1 TACH；GPIO4 读取 FAN2 TACH。
- 实测 D1 更换后，FAN1 与 FAN2 均可驱动、调速并读取测速脉冲。
- PWM 逻辑反相：GPIO 高电平占空比越高，风扇实际占空比越低；GPIO 高阻释放时风扇回到全速。

## 设计约束

- 两只风扇共享 PWM，因此温度策略输出一个共同档位；两路 TACH 仅用于分别显示和故障判断。
- 低温停转需要主动把 PWM 总线保持低电平；复位、初始化、通信故障时应保持或回到全速。
- 4 线风扇从停止恢复时需要短暂全速 kick-start，避免低占空比下无法启动。
- 触摸屏空间有限，配置应使用分步编辑和明确的保存反馈，避免在一页塞入过多控件。
