ESP32-S3-Touch-LCD-1.47-M；底面为风扇座、电源座及全部贴片元件。

## 文件用途

- `GB10-Fan-RevB-20260909.zip`：嘉立创原样导出的 Gerber 和钻孔包，PCB 报价/下单使用此文件。
- `GB10-Fan-RevB-BOM-20260909.csv`：11 种料、16 个元件，包含真实 LCSC 料号。
- `GB10_Fan_RevB_CPL_20260909.csv`：原生贴装坐标，毫米单位；文件实际为 UTF-16LE、Tab 分隔。保留原格式，嘉立创不需要再次镜像底面坐标或旋转角度。
- `GB10-Fan-RevB-PCB.epro2`、`GB10-Fan-RevB-Schematic.epro2`：含真实器件库的原生备份。
- `native-pcb/`、`native-schematic/`：上述备份的解压审计副本。
- `gerber/`：制造 ZIP 的原样解压副本。
- `pin-bom-mechanical-audit.json`、`manufacturing-audit.json`：文件核对结果，不能替代工厂 DFM。
- `gerber-top.png` / `gerber-bottom.png`：直接从原始制造 ZIP 渲染的裸板预览；同名 SVG 保留矢量图。

Gerber、钻孔和 CPL 坐标的原点一致，位于板左下角向右 20.30651006 mm、
向上 11.78500056 mm 处。因此部分坐标为负值是正常的，不要只平移其中一份文件。

## 装配与连接

```text
GB10 USB-C ── USB线 ── 显示模块 USB-C（ESP32/屏幕供电与通信）
                         │ 两排焊好排针，USB端对准PCB的USB <标识
                         ▼
                    JDISP1 / JDISP2（顶面排母）

12V充电头 ── 支持12V协商的Type-C转DC5521线 ── J1（中心正极）
                                                  │ F1、D1
                                                  ├─ J2/FAN1 ── TL-C14C 140mm
                                                  └─ J3/FAN2 ── AFB0612LB 60mm
ESP32 GPIO1 ── Q1开漏PWM ────────────────────────── 两只PWM端
ESP32 GPIO2 ◀───────────────────────────────────── FAN1测速
ESP32 GPIO4 ◀───────────────────────────────────── FAN2测速
```

风扇插座针序为 1 GND、2 +12V、3 TACH、4 PWM，以连接器实际针号和定位挡片
为准，不根据线色猜针序。风扇电源并联；可改用大风扇自带分接口，但只能回传
一只风扇的测速。两个独立接口保留，可分别监测堵转。

屏幕排母只有 GND、3V3、GPIO1/2/4 有连接。VBUS、VBAT 均不连接风扇电源。
排母间距 17 mm、针距 2.54 mm、塑高 8.5 mm；四个 M2 安装孔直径 2.2 mm。
使用绝缘隔柱保持平行，最终隔柱长度应按实物排针完全插入后的间距选择。
底面插头、DC线缆和高电容需在外壳里留空间，不能只按裸PCB厚度设计安装槽。

11 个贴片件全部在底面：C1/C2、D1/F1、Q1、R1–R6。
5 个插件为 J1/J2/J3（底面）及 JDISP1/JDISP2（顶面）。普通 SMT 服务不等于
五个插件全部焊好；报价时需核实插件代焊服务，或留作手焊。排母必须先用显示板
或定位治具校正平行度，再焊牢，避免两排歪斜导致不能插入。

## 首板验证

首板上电前，用万用表检查 J1 极性、12V与3V3不短路、排母无错位，再用限流
12 V 电源连接风扇。验证上电默认全速、25 kHz PWM、两路测速、拔USB/通信超时
回退全速、正常温升和启动成功。GPIO PWM 经Q1反相，风扇高电平占空比等于
1减去GPIO高电平占空比。每转脉冲数需用实物或型号资料校准。

这是一版待工厂制造审查和首板验证的设计资料，不代表已经过实物测试。
