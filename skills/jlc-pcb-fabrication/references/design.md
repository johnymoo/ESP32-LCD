# 设计与工具选择

## 把接口和机械证据放在画板之前

准确型号及后缀来自用户实物和厂家资料。“带针”通常只表示已焊排针，并不保证双排编号、排距、高度或 GPIO 一致。商品标题、效果图和相似模块不能单独支持引脚判断。

建立逐针映射：厂家连接器脚号 → 物理排/位置 → 本板焊盘号 → 电源或网络 → MCU GPIO。标明观察方向（元件面、焊接面、插合面），交叉核对厂家原理图和机械图；双排可能是奇偶编号，不能默认前半/后半分排。检查启动配置脚、USB、显示/触控、存储和板载外设占用。仍无证据的关键脚位不能用于制造定稿。

锁定板框、孔坐标、排针中心距、针距、接触跨度、排母塑高和插入深度。将外接模块/线缆、USB-C、按键、显示玻璃、天线净空和烙铁操作空间纳入摆件约束。顶底翻转后再核对插合方向；3D 预览不替代尺寸图或最终实物试插。

## 电气设计

先画原理图并定义网络，再同步 PCB。明确电源极性、输入范围、稳态和启动电流、保护器件、允许压降、信号电压及共地关系。按电流、铜厚、走线长度和温升约束选择电源路径，不凭“比信号粗”断言载流合格。

对开漏接口，核对上拉的来源和电压、开关管脚序、输入门限、上电/复位状态。外部设备掉电与 MCU 掉电分别分析；硬件默认态和软件通信超时回退分别列入验证。

四线风扇项目的特别检查：确认每款风扇电源/测速/PWM 脚序及电气规范；菊链连接不等于电机电源串联，多个测速输出不能直接短接。GPIO 推挽是否可直连要根据接口规范判断。MOSFET 下拉可能使 PWM 占空比反相；共享 PWM 总线也要核对各风扇上拉的兼容性和总灌电流。不要将某块板的 GPIO、频率或电阻值当作通用默认值。

## 器件标准化和装配方式

尽早选择真实厂商型号及立创料号，核对数据表、Symbol 脚号、Footprint 焊盘和焊接方式。改 Supplier Part 字符串不能把占位器件变成真实器件；换器件需一起核对 Device/Symbol/Footprint，并恢复网络端点。

手焊优先选择用户工具能够操作的封装，兼顾尺寸、可购性和电气要求；1206、0805、直插并非所有项目的硬性标准。摆件时避免高大插件挡住贴片焊脚，尤其电解电容、DC 座和双排插座。先确认再布局，成本评估包括可能产生的双面加工、插件工程、治具和特殊间距费用。

## 本地与嘉立创 EDA 衔接

- 检测 macOS/Ubuntu 实际已有工具及版本；远程操作限定在用户指定目录，不安装或改动无关服务。
- 现有嘉立创原生工程：在线最终校核，保存包含库的原生导出；本地处理备份、资料、确定性审计和独立 Gerber 检视。
- 现有 KiCad 工程：在原生工具中 ERC/DRC、生成制造文件，按商家当前字段格式配单。不能仅凭安装 KiCad 就声称能导入 EPRO2/EPRU，转换后需另行验证网络/坐标/层/封装。
- 修改原理图后用 EDA 的更新 PCB/ECO 功能，核对新增/删除器件及焊盘网络，避免只改铜线留下源图不同步。

嘉立创 File Source 的直接编辑是有格式风险的恢复手段，并非默认工作流。确有必要时先备份原生项目、导出当前版本样例，按该版本格式小步导入并重新打开、DRC、对照网络。2026-09 的一次 Pro 编辑中，末记录追加分隔符 `|` 导致 Invalid format；版本变化时应重查，不能照抄历史文本生成器。替换符号还曾丢失 NO_CONNECT 标记，需在替换后检查并补回真正未连接脚的标记，不能用标记掩盖缺线。
