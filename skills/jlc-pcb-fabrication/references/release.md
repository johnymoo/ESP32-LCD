# 制造发布校核

## 分开保存各层证据

| 校核 | 能证明什么 | 不能替代什么 |
|---|---|---|
| 原理图 ERC/DRC | 当前规则下的源图连接检查 | 电路功能、器件额定值分析 |
| PCB DRC | 当前规则下的铜线、孔和焊盘几何检查 | 真实外接模块尺寸、加工承接 |
| BOM/网络/几何独立审计 | 同版设计、料号、引脚、机械约束的一致性 | EDA 完整规则引擎 |
| Gerber/钻孔复核 | 最终制造输出内容 | 未导出的原生数据、实物性能 |
| PCB/SMT DFM | 工艺阈值、装配模型的检查结果 | 厂方最终审核、实物装配 |
| 订单市场审核 | 商家对该订单的当前审核状态 | 生产稿确认、投产、验收 |

每份证据带版本、导出时间、输入文件和结果。修图/换料/换封装后，旧证据不能为新的制造包背书；重跑直接受影响及导出一致性检查即可，不无理由反复重跑无关测试。

## 发布前的有效检查

核对原理图与 PCB 器件集合、焊盘网络、BOM 料号和数量；排除遗漏器件、重复位号、未布线、错误 NC、意外悬空电源。确认连接器方向、孔位/孔径、成品外形和板边插座的实际机械含义。

打开最终 Gerber/钻孔，检查电源铜路、覆铜、天线净空、阻焊开窗、露线、丝印压焊盘、孔环和异形槽孔。验证解析器确实支持输出中的指令；一次旧解析器对 G85 槽孔和绘图的误处理不应被误判为制造文件损坏。某面无贴片元件时，没有该面的锡膏层可以是正常输出。

封装属性是线索，最终层内容才是证据：例如负 paste expansion 与自定义锡膏图形可能共同定义开口，不能只改一个属性而重复开窗。含 SVG mask/filter 的预览需支持这些特性的渲染器，空白/黑块不是铜层缺失的充分证据。

## DFM 残余项

保留软件原始“危险/警告/良好”计数。逐项记录对象、测量值、阈值、所选工艺是否适用、厂家尺寸证据、处置和待确认者。不要为了全绿而缩孔、虚报间距或删去用户需要的插件。

例如波峰焊治具阈值不一定适用于逐件手焊，但烙铁可达性和桥连风险仍要核对；板边连接器与板框相交不等于器件位置错误；模型文字遮挡不等于 Gerber 丝印压焊盘。解释提示与获得厂家承接确认是两件事，关键物理/电气冲突未解决时不能给出可制造结论。

## 工厂装配才需要的 CPL 核对

核对单位、原点、层名、X/Y、旋转和位号，BOM/CPL/PCB 必须来自同一版。逐一查看有极性器件、连接器和非对称封装的实际 pin 1、正负极及 G/S/D，不能只看模型外形是否居中。

EDA 与商家库零度定义不同可能仅影响个别器件。保留原 CPL，只对已确认对象输出单独校正版，记录位号、字段、前后值、原因；保持编码/分隔符/其他坐标字段，重新导入同版 BOM+CPL，验证无需再次手工旋转。不要整体镜像，也不要给所有底面器件统一加 180°。某案例的四个器件校正不能推广到下一块板。

## 发布包和状态记录

制造包通常含原生原理图/PCB（包括依赖库）、Gerber ZIP/钻孔、BOM、适用时的 CPL、装配/层预览、校核报告、制造备注和校验清单。注明唯一送厂包；旧版和失败的预览另标历史，避免同名 ZIP 被选错。

对已冻结包在复制、传输后校验：macOS 可在发布目录执行 `shasum -a 256 -c SHA256SUMS`，Ubuntu 可用 `sha256sum -c SHA256SUMS`。已有清单失败时检查差异，不能重写清单来掩盖制造字节变化。订单动态记录放在发布目录之外，免得每次付款/物流更新改动冻结包。

Git 提交前剔除个人地址、发票资料、凭据和临时支付链接。若隐私检查将 EDA 时间戳/坐标当账号，检查命中上下文并保留数字；不应用会破坏工程的脱敏补丁，也不擅自关闭检查。可以独立提交未受阻的 skill/文档，明确工程迁移仍未完成，不能把局部发布说成全项目已发布。

首板验证记录应包含断电连通/短路、极性、限流上电、接口与机械试插、实际负载启动和温升、控制/测速及故障回退。执行实物测试需要对应硬件和测量工具；未执行的项如实保留待测。
